# 2Q PHỞ Website

## 写真を追加
`images` フォルダへ写真を入れてください。

- `hero.jpg` = トップ写真
- `interior.jpg` = 店内
- `gallery-01.jpg` ～ `gallery-05.jpg` = ギャラリー

料理写真は `script.js` の各メニューの `image:""` を変更します。
例：`image:"images/pho-bo.jpg"`

## GitHub Pages
Repositoryへ `index.html` / `style.css` / `script.js` / `images` をアップロード。
Settings → Pages → Deploy from a branch → `main` / `/root` → Save。
