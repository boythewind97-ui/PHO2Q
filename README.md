# 2Q PHỞ Website v2

### ファイル構成
すべて `index.html` と同じ階層です。`images/` フォルダは使いません。

- `index.html`
- `style.css`
- `script.js`
- `logo.png` ← 提供いただいた看板画像からロゴ部分を切り出したもの
- `hero-banner.png` ← 提供いただいた看板・店舗情報のデザイン
- `set-menu-poster.jpg` ← 提供いただいたセットメニュー画像
- `interior.jpg` / `gallery-01.jpg` ... ← 後から実写真に差し替え
- 料理・ドリンク用画像ファイル ← 後から実写真に差し替え

### 写真の入れ替え
たとえば `set-01.jpg` を同じフォルダにアップロードすると、セット1の写真として使えます。
GitHubではファイル名の大文字・小文字も一致させてください。
